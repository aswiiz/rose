Pavithra proposal website
-------------------------
Deploy on Vercel:
1. Upload this folder to a GitHub repository (index.html at the repository root).
2. Import the repository into Vercel.
3. Framework preset: Other. Build command: leave blank. Output directory: leave blank (root).
4. Deploy.

The site is a static HTML page. Google Fonts require internet access; if unavailable, it falls back to system fonts.
The sound toggle uses a soft synthesized tone and starts only when clicked.
